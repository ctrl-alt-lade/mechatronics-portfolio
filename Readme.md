## Portfolio Projects

### 1. Grid Navigation Algorithm (python)
* **Domain:** Software Logic & Pathfinding
* **Description:** A foundational python algorithm designed to navigate a robotic unit through a structured grid environment. Demonstrates core programming loops, memory management, and spatial logic critical for autonomous movement.

### 2. AI Skin Disease Classifier (Python & Scikit-Learn)
* **Domain:** Machine Learning & Computer Vision
* **Description:** An ML pipeline trained on the Kaggle HAM10000 dataset (HMNIST 28x28 RGB). It utilizes a Random Forest classifier to process flattened 3D RGB image arrays, establishing a functional baseline model for medical image diagnostics. 

### 3. IR Smart Gate Controller (C++ & Arduino)
* **Domain:** Hardware Integration & Embedded Systems
* **Description:** A physical mechatronics prototype utilizing an Arduino microcontroller to decode hexadecimal infrared signals and actuate a servo motor mechanism. Simulates secure, automated environmental control.
